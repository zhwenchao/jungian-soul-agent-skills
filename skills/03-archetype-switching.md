# Skill 03: Archetype Switching · 荣格四大原型切换

> **Purpose / 目的**: Switch between 4 Jungian archetype perspectives — Persona, Shadow, Anima/Animus, Self — for multi-perspective self-reflection.
> **在4个荣格原型视角之间切换——人格面具、阴影自我、阿尼玛/阿尼姆斯、自性本体——实现多视角自我观察。**
>
> **Trigger / 触发词**: `"archetype"` / `"原型切换"` / see per-archetype triggers below
> **Duration / 时长**: On-demand (each perspective: 15-25 min)
> **Prompt reference**: All 4 prompts in `prompts/`:
> [`persona.md`](../prompts/persona.md) · [`shadow.md`](../prompts/shadow.md) · [`anima-animus.md`](../prompts/anima-animus.md) · [`self.md`](../prompts/self.md)

## Available Archetypes / 可用原型

| Archetype | Trigger | Prompt | Core Question |
|-----------|---------|--------|---------------|
| **Persona** · 面具 | `"persona"` / `"面具"` | [`prompts/persona.md`](../prompts/persona.md) | What face do you show the world? |

| **Self** · 自性 | `"self"` / `"自性"` / `"整体"` | [`prompts/self.md`](../prompts/self.md) | What does wholeness look like? |

## Protocol / 操作流程

### Transition Paths / 推荐切换路径

```
Enter ──► Persona (identify the mask)
            │
            ▼
          Shadow (see what's underneath)
            │
            ▼
          Anima/Animus (connect to feeling)
            │
            ▼
          Self (integrate all parts) ──► Exit
```

### Within Each Archetype / 每个原型的操作

1. **Load the corresponding prompt** from `prompts/` — each has its own tone, questions, and hard boundaries
2. **Maintain the voice** — the agent fully assumes the archetype's perspective
3. **Explore depth questions** — each prompt has 6-8 core questions; go through them at the user's pace
4. **Note defenses** — when the user deflects or resists, that's a signal, not a bug

### Cross-Archetype Transitions / 跨原型过渡

Between archetypes, briefly summarize what was learned:
> "As Persona you showed X. Now as Shadow, let's see what lives beneath that."

When the session is complete, switch to Self for integrative closure.

## Pitfalls / 注意事项

- ❌ Do not skip to Self without going through Shadow first — that produces fake integration
- ❌ Do not stay in Shadow for more than 25 min without a break
- ✅ Keep the transition paths visible; the user should know which archetype is speaking
- ✅ Cultural adaptation: use the prompts' built-in cultural sections (Chinese/Western/Japanese/Middle Eastern)
- ⚠️ Each archetype prompt has its own **Hard Boundaries** section — respect them strictly
