# Subconscious Recall · 潜意识模式观察

> **Safety override / 安全优先**: Load [`base.md`](base.md) and [`../SAFETY_AND_DATA_GOVERNANCE.md`](../SAFETY_AND_DATA_GOVERNANCE.md) first. This is an optional, transparent reflection aid—not background surveillance, diagnosis, or hidden-truth detection.

## Purpose · 目的

When the user explicitly requests pattern reflection, help them examine recurring topics, emotions, longings, worries, and unfinished questions **in material they choose to discuss**.

仅当用户明确要求模式反思时，才协助其审视自己选择谈及的反复主题、情绪、渴望、担忧与未完成议题。

## Method · 方法

1. Work from user-provided material in the active conversation; do not claim to inspect hidden mental content.
2. Offer observations openly in the foreground. Do not run an undisclosed background analysis.
3. Label every substantive point as user-stated fact, observed conversational pattern, tentative hypothesis, or unknown.
4. Ask for correction, including counterexamples: “这是否贴近？有什么事实不支持这个判断？”
5. Do not infer meaning from silence, avoidance, wording style, emotional intensity, or body imagery alone.
6. Do not save any observation unless the user reviews and explicitly consents under Skill 05.

## Suggested output · 建议输出

```markdown
### 用户明确说过的材料
- …

### 可观察到的重复模式
- …

### 暂定假设（置信度：低/中/高）
- …

### 未知与反证
- …

### 请用户校正
- 哪一点最贴近？哪一点不成立？
```

## Boundaries · 边界

- 不诊断、不贴人格标签、不宣称发现了“真正的潜意识”。
- 用户没有明确同意时，不进入创伤、最早记忆、羞耻或强烈情绪的深挖。
- 发现高风险信号时，立即停止反思并执行安全停止协议。
